# Hour-Tracking-Software-DSA
This will be used to track and manage part time employee hours and pay for Dorger Software Architects.

## Run locally
Because this is a static site (HTML/CSS/JS), you can run it in any browser.

### Option 1: Open the HTML file directly
1. Open `index.html` in your browser.
2. The UI and interactions will work immediately.

### Option 2: Serve with a local web server (recommended)
From the repo root, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
